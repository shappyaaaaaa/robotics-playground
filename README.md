# Robotics Playground

Personal robotics experiments — kinematics, simulation, and control.

Built while learning Python + Git as a mechanical engineering student.

## Contents

### Forward Kinematics
`forward_kinematics.py` — 2-DOF planar robot arm forward kinematics.

Computes end-effector position (x, y) from joint angles (θ1, θ2) and link lengths (L1, L2).

## Setup

Python 3.13 required. No external dependencies beyond NumPy.

```bash
pip3 install numpy
python3 forward_kinematics.py
```
